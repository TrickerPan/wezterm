## 1. Pane 管理快捷键

- [x] 1.1 在 macOS keys 表中添加水平分割 Pane 快捷键 (`CMD+Shift+-` → `SplitHorizontal`)
- [x] 1.2 在 macOS keys 表中添加垂直分割 Pane 快捷键 (`CMD+Shift+\` → `SplitVertical`)
- [x] 1.3 在 Windows/Linux keys 表中添加水平分割 Pane 快捷键 (`CTRL+Shift+-` → `SplitHorizontal`)
- [x] 1.4 在 Windows/Linux keys 表中添加垂直分割 Pane 快捷键 (`CTRL+Shift+\` → `SplitVertical`)
- [x] 1.5 在两个平台的 keys 表中各添加 4 个 Pane 导航快捷键 (`ALT+方向键` → `ActivatePaneDirection`)
- [x] 1.6 在 macOS keys 表中添加 Pane 大小调整快捷键 (`CMD+ALT+方向键` → `AdjustPaneSize`)
- [x] 1.7 在 Windows/Linux keys 表中添加 Pane 大小调整快捷键 (`CTRL+ALT+方向键` → `AdjustPaneSize`)

## 2. 复制模式快捷键

- [x] 2.1 在 macOS keys 表中添加进入复制模式快捷键 (`CMD+Shift+X` → `ActivateCopyMode`)
- [x] 2.2 在 Windows/Linux keys 表中添加进入复制模式快捷键 (`CTRL+Shift+X` → `ActivateCopyMode`)

## 3. 字体大小控制快捷键

- [x] 3.1 在 macOS keys 表中添加放大字体快捷键 (`CMD+=` → `IncreaseFontSize`)
- [x] 3.2 在 macOS keys 表中添加缩小字体快捷键 (`CMD+-` → `DecreaseFontSize`)
- [x] 3.3 在 macOS keys 表中添加重置字体快捷键 (`CMD+0` → `ResetFontSize`)
- [x] 3.4 在 Windows/Linux keys 表中添加放大字体快捷键 (`CTRL+=` → `IncreaseFontSize`)
- [x] 3.5 在 Windows/Linux keys 表中添加缩小字体快捷键 (`CTRL+-` → `DecreaseFontSize`)
- [x] 3.6 在 Windows/Linux keys 表中添加重置字体快捷键 (`CTRL+0` → `ResetFontSize`)
